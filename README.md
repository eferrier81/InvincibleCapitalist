# InvincibleCapitalist

Recréation du jeu **AdVentureCapitalist** sous forme de jeu de gestion incrémentale, avec un backend **GraphQL (NestJS)** et un frontend **Angular**, dans l'univers de la bande dessinée / série **Invincible**.

Projet réalisé dans le cadre du module *Architectures orientées service* (ISIS, FIE5, S9).

## Auteurs

- Enzo FERRIER
- Ethan CABANES

## Structure du projet

```
InvincibleCapitalist/
├── backend/   # API GraphQL (NestJS, schema-first)
├── frontend/  # Client Angular (à venir)
└── docs/      # Dossier de conception
```

## Backend

```bash
cd backend
npm install
npm run start:dev
```

Le playground GraphQL est disponible sur `http://localhost:3000/graphql`.
